# 🎵 SoundCloud Telegram Music Bot

Полнофункциональный Telegram-бот для поиска и скачивания музыки с **SoundCloud** с поддержкой **Inline-поиска**, мгновенного кэширования аудиофайлов, конвертации в MP3 и вшивания обложек.

---

## ⚡ Особенности

* **Инлайн-поиск (Inline Mode)**:
  * Вводи `@имя_бота <название трека>` в любом чате или группе.
  * Мгновенный вывод треков с обложками, длительностью и исполнителем.
  * Если трек уже был скачан ранее — отправляется **мгновенно** напрямую из кэша Telegram (`InlineQueryResultCachedAudio`).
  * Если трек новый — отправляется карточка с кнопкой «📥 Скачать MP3».
* **Скачивание по прямым ссылкам**:
  * Поддерживает ссылки вида `https://soundcloud.com/...` и короткие ссылки `https://on.soundcloud.com/...`.
  * Поддерживает распознавание плейлистов.
* **Поиск в диалоге с ботом**:
  * Отправь боту любое название трека или имя музыканта текстом — он найдет топ-5 треков с кнопками скачивания.
* **Качественное аудио и метаданные**:
  * Автоматическая конвертация в MP3 (192 kbps) через `FFmpeg`.
  * Вшивание тегов ID3 (название, автор) и обложки высокого разрешения (500x500 px) через `mutagen`.
* **База данных и кэш**:
  * Локальная база данных SQLite (`aiosqlite`).
  * Повторные запросы одних и тех же треков не расходуют трафик и процессор сервера.
* **Обход защит**:
  * Автоматический парсинг актуального `client_id` из скриптов SoundCloud.
  * Корректная обработка треков с DRM-защитой (SoundCloud Go+).

---

## ⚙️ Важная настройка: включение Inline Mode в Telegram

Чтобы инлайн-поиск `@бот запрос` заработал в Telegram, его нужно включить в `@BotFather`:

1. Открой диалог с [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправь команду: `/setinline`
3. Выбери своего бота из списка.
4. Введи текст-подсказку (плейсхолдер), например: `Поиск треков на SoundCloud...`
5. Готово! Теперь инлайн-поиск активирован.
